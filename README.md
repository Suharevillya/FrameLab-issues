# FrameLab — bug reports

This repository collects bug reports for [FrameLab](https://framelab.fly.dev), a browser-based
2D frame and truss FEM editor with Eurocode steel, concrete and joint checks. The source code
is kept private; this repository only holds issues.

**[Report a bug →](https://github.com/Suharevillya/FrameLab-issues/issues/new?template=bug_report.yml&labels=bug)**

It helps to include the steps you took, what you expected (with the value and its source,
for a wrong result), and the project file (.fl, exported from the start page).
